我是 Garfield Zhu，一个普通又有点懒散的软件工程师。

我喜欢写新鲜、有趣的代码，也每天用拿铁和美式当燃料进行产出。工作之外，我会晒晒下午的太阳，玩游戏，看动画，偶尔也享受一点热烈的生活。对我来说，写代码和这些小快乐放在一起，才算平衡。

<AboutSectionLabel label="engineer" />

刚开始工作时，我热衷于 Java、C++、Python 和 JavaScript 之间的论坛战争，为谁是“最好的”技术栈争得头破血流。

后来又混迹于 Angular 和 React 的键盘大战，以及 Golang 和 Rust 的无尽争论。每个阵营都有自己的忠实拥护者，没有人肯退让一步。

几年之后我发现，我其实每天是燃烧咖啡，拿锤子、钻头、锯子在敲代码。看起来像在造宇宙飞船，其实毫不意外的，我的技术栈就是个 <NeonFlicker primary="NULL" alternate="FULL" />。

现在进入 LLM 时代，大家都在谈 vibe coding，却很少再谈 pair programming，仿佛“古法编程”快要变成博物馆里的木乃伊。对一个程序员来说，这是有点危机感，但它也宽阔了我的视野，让效率高到以前想不到的地方。

现在这些智能体不只是像电钻，更像 3D 打印机：有时我只交一张蓝图，有时给一个粗糙模板也够了。做软件开始不像一门硬邦邦的工程，更像一种手艺，甚至有点艺术。现在我最喜欢 Codex 和 OpenCode，WorkBuddy 也挺好用。可惜 Dario 这位老哥还是不愿意让中国用户用 ClaudeCode，我只能摊手。
