你好，我是 Garfield Zhu，一个平平无奇又闲散的软件工程师。

我热衷于写写新鲜、有趣的代码，拿铁和美式是我创意的燃料，必须灌满。工作之外，我享受晒着慵懒的阳光玩游戏、看动画，偶尔也享受一点生活中额外的冲劲与冒险。对我来说，写代码和这些小快乐放在一起，才算平衡。

<AboutSectionLabel label="engineer" />

多年前刚开始工作时，我热衷于 Java、C++、Python 和 JavaScript 之间的编程语言战争，誓要为谁是“最好的”技术栈争得头破血流。

后来又混迹于 Angular 和 React 的键盘大战，以及 Golang 和 Rust 的各种争论。技术流派间像极了宗教信仰，每个阵营都有自己的忠实拥护者。

多年后我发现，我其实每天就是咕咚咕咚灌满咖啡，拿锤子、钻头、锯子在敲敲打打代码——语言和框架什么的区别无非是榔头和老虎钳的不同，有的活都能用，有的活各有各的擅长罢了。
一天天的看起来像在给宇宙飞船拧螺丝，但我的技术栈已经慢慢变成了 <NeonFlicker primary="NULL" alternate="FULL" />。

从大模型时代开始，人人都在谈vibe coding，已经没人再提结对编程了。AI的飞轮带着时代的车轮前进，还抓着“古法编程”抱残守缺的人早晚被碾得粉碎。对一个程序员来说，此诚危急存亡之秋也。但它带来的更多机会和能力，让个人的视野宽广到前所未有的水平，让个人的产出不逊于曾经的小团队。

作为工具，现在这些Agent的变革并非像电钻这种纯粹的效率革命，而是更像3D打印机带来的思维革命：有时我只交一张蓝图，有时给一个粗糙模板也够了。做软件开始不像一门硬邦邦的工程，更像一种手艺，甚至有点艺术。现在我最喜欢 Codex 和 OpenCode，最中国大陆的办公环境下的话目前 WorkBuddy 也挺好用，但愿腾讯这次能把好人做的久一些。ClaudeCode 可能依然会是GOAT, 可惜愤怒的Dario死死地攥着它，对中国用户充满恶意。不知道几年后再来这段历史，会是哪个胜者吞下所有呢。
