# Site-wide English and Chinese localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add persisted English/Simplified-Chinese localization with `/zh-CN/...` routes, translated MDX/About fallbacks, localized Live2D dialogue, and verified English regression behavior.

**Architecture:** Keep all existing unprefixed English route files and URLs. Add a typed locale provider/dictionary for client UI, shared locale-aware render props for server components, and explicit `/zh-CN` route wrappers for Chinese pages. Contentlayer derives translation identity from `_cn.mdx`, while canonical selectors keep English aggregates free of duplicate translations. The separate Live2D repository receives locale catalogs and a runtime locale event; the blog pins its widget script to the resulting immutable commit.

**Tech Stack:** Next.js App Router 15, React 19, Contentlayer2, MDX, TypeScript/JavaScript dictionaries, Node `node:test`, Rollup-built Live2D widget, Vercel deployment, in-app Browser validation.

## Global Constraints

- Supported locale codes are exactly `en` and `zh-CN`; new visitors default to `en`.
- Persist the selected locale under `alohayo:locale`; do not auto-detect browser language for a new visitor.
- Existing English URLs, English strings, layouts, playgrounds, and behavior must remain unchanged when `showLocaleSwitch` is `false`.
- Chinese public routes use `/zh-CN/...`; English routes remain unprefixed.
- Blog translation source files use `<slug>_cn.mdx`; `_cn` slugs never appear as public English slugs.
- Missing blog translations redirect to the original English URL while retaining the saved Chinese UI locale.
- English aggregate surfaces exclude `_cn` and `translationTest` documents; Chinese aggregates substitute real translations and otherwise link to English fallback posts.
- Every UI dictionary key exists in both locale dictionaries; English values preserve current rendered copy.
- Live2D catalogs preserve selector, placeholder, date/hour-range, and message-shape parity.
- Use the exact temporary test pair specified by the design, deploy it, validate it, delete it, then redeploy and validate fallback.
- Run fresh automated tests and production builds before claiming completion.
