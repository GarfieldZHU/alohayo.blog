# Bilingual pages

The site renders English by default and supports Simplified Chinese with the `文/A` control. The selected code is `en` or `zh-CN` and is saved as `alohayo:locale` in local storage.

## URLs

English routes remain unchanged:

```text
/blog/webgpu/
```

Chinese pages use a locale prefix:

```text
/zh-CN/blog/webgpu/
/zh-CN/about/
/zh-CN/agent/
```

This keeps old links stable and gives translated posts a real, indexable URL. A blog translation is an `_cn` sibling in `data/blog`, for example `webgpu_cn.mdx`. The Chinese index uses that document when present; a missing translation links back to `/blog/webgpu/`.

## Adding content

UI strings belong in both dictionaries in `lib/i18nMessages.ts`. Blog prose remains English unless a translation is requested. When translating a blog, keep the same slug and add the `_cn` sibling so the two pages share a translation key.

The canonical selectors in `lib/blogI18n.ts` keep `_cn` files out of English listings, tags, search, RSS, and sitemap. Do not filter them ad hoc in a page.

## Chinese terminal poetry

The Chinese Home Terminal's `今日随机诗词` action calls the public [诗泉 API](https://poetry.palemoky.com/):

```text
GET https://poetry.palemoky.com/api/poems/random?lang=zh-Hans
```

The client reads `data.title`, `data.content`, `data.author.name`, `data.dynasty.name`, and `data.type.name`, then renders the poem on the paper-style card. It needs no API key; keep requests user-triggered and respect the service's basic rate limit.

## Pokémon names

PokéAPI does support localized names. The Pokémon response points to a Pokémon Species resource, whose `names` list carries a language record. The Home Terminal reads `en` for English and `zh-hans` for Simplified Chinese, while keeping the canonical API name for the 52Poké wiki link. Species names are cached in memory for the session to keep random draws friendly to the API.

## Live2D locale contract

`app/layout.tsx` loads an immutable Live2D widget revision. The widget receives both catalog URLs and exposes `window.WaifuWidget.setLocale(locale)`. `LocaleProvider` also emits `alohayo:locale-change`; the widget listens to that event and replaces its catalog without mounting a second assistant.
